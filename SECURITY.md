# LegacyGuard Security Policy

LegacyGuard is not deployed for public use and is not approved for real
sensitive data.

Do not open a public issue for a suspected vulnerability. Follow the private
reporting process in [docs/SECURITY.md](docs/SECURITY.md). GitHub Private
Vulnerability Reporting and a monitored backup channel must be enabled and
tested before public participation opens.

The latest maintained pre-pilot release receives security fixes. A formal
supported-version table, response targets, safe-harbor language, and coordinated
disclosure process must be reviewed before a pilot.
